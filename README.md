# QuotesStoicismParcer

Парсер цитат стоиков с сайта https://stoicfork.online/

## Стек
- python 3.14
- requests
- BeautifulSoup4

## Как запустить
1. Склонировать репозиторий.
2. Создать виртуальное окружение:

```
python -m venv venv
```

3. Установить зависимости:

```
pip install -r requirements.txt
```

4. Запустить

```
python main.py
```
